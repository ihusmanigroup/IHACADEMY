IH ACADEMY
 Winter Internship 2026-27
 Backend Engineering
 Node.js, Express, databases, authentication, API design, security, testing, documentation
 and deployment.
Program length
4 weeks
Weekly structure
4 track assignments + required free course(s)
Difficulty path
Easy -> Intermediate -> Advanced -> Capstone
Visibility rule
Intern sees only the track selected in the application
Unlock rule
Next week unlocks only after all previous-week assignments and required course proofs are
approved
Submission types
GitHub repository, deployed link when applicable, notes/comments, PDF evidence report and
optional supporting file
Program rules
• This document replaces the old eight-week/summer assignment bank for the Winter Internship portal.
• Week 1 contains two required free courses; Weeks 2-4 contain one required free course each.
• All four assignments in a week are mandatory. Course certificates are also mandatory.
• A submission may be Draft, Submitted, Changes Requested or Approved. Only Approved items count toward
unlocking.
• Plagiarism, copied repositories, exposed API keys, fake deployments or fabricated screenshots result in
rejection.
• Deadlines, opening dates and review windows must be admin-configurable; do not hardcode them in the
frontend.
Standard PDF evidence report
• Cover page: intern name, track, week, assignment, repository URL and live URL.
• 1-2 pages of implementation summary and architecture/folder structure.
• Screenshots of required features and important validation/error states.
• Testing table with scenario, expected result, actual result and pass/fail.
• Challenges, limitations and what the intern would improve next.

REST Notes API
Assignment question: Build a versioned REST API for personal notes with title, body, tags, pinned status and
timestamps.
Required work
• Use Node.js + Express with a clean routes/controllers/services structure.
• Use MongoDB or PostgreSQL with documented schema decisions.
• Validate all request data and return consistent JSON errors.
• Implement create, list, single read, update and delete endpoints.
• Add pagination, text search and tag filtering.
• Return 404 for missing resources and 400/422 for invalid data.
Expected deliverables
• GitHub repository with meaningful commits
• Postman/Bruno collection or OpenAPI documentation
• .env.example and setup-ready README
• PDF report with endpoint table, schema diagram and test screenshots
